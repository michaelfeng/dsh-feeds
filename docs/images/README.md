# Screenshots

README screenshots use the plugin UI with demo data. Use fictional subscriptions and article text
(e.g. feed URLs under the reserved `.example` domain). Keep personal feeds, reading history,
local paths, and unrelated app panels out of frame. Capture at native resolution, crop to the
relevant UI, and use a subtle tinted frame so white panels stay visible on GitHub. Keep each
file under 500 KB.
